# phd-data

Data storage from my phd-experiments.

Each folder holds the data of one article. The folder name is the working name of the article.

| Folder | Content |
|---|---|
| `accel-nssm-vs-classical-crane` | Simulation data of an overhead crane, accompanying a manuscript in preparation |

Every folder has its own README with the description of the files and a `MANIFEST.sha256` file. To check a download, run `sha256sum -c MANIFEST.sha256` inside the folder.

Additional sets will be added.
